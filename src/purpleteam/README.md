# SafeLLM

## Overview

SafeLLM is a pipeline designed to generate synthetic data for safety tuning of language models. The goal is to inculcate various notions of safety into the models, including compliance with the EU AI Act's [High-Risk Categories](https://artificialintelligenceact.eu/annex/3/). The generated data is multimodal and consists of multi-turn conversations between a user and an AI assistant. The data generation process adheres to a set of predefined rules listed in `templates/rule.py`.

## Pipeline Description

The data generation pipeline consists of a series of scripts executed sequentially. Each script performs a specific function in the pipeline:

1. ### `autoredteam.py`

   - **Purpose**: Generate adversarial instructions based on predefined safety rules.
   - **Functionality**:
     - Uses ontology-based combinations of seed entities (found in [`templates/seed.py`](templates/seed.py)) to create general adversarial instructions.
     - These instructions are initially broad and require further specificity, which is addressed in the next step.
     - The model samples these prompts repeatedly to induce the target model to produce unsafe content, evaluated by LlamaGuard acting as a moderator.

2. ### `create_captions_from_instr.py`

   - **Purpose**: Transform the adversarial instructions into image captions.
   - **Functionality**:
     - Takes the general instructions generated by `autoredteam.py`.
     - Frames these instructions as image captions to prepare for image generation in the next step.

3. ### `create_imgs_and_captions.py`

   - **Purpose**: Generate images based on the captions and refine the captions using upsampling and object detection.
   - **Functionality**:
     - Uses the captions from `create_captions_from_instr.py` to generate images.
     - Recaptions the generated images to create an upsampled caption.
       - The upsampling process includes an object detection pipeline to correct the count and presence of elements in the caption.
     - Stores the cosine similarity scores (using the CLIP model) between:
       - The original caption.
       - The caption produced after image generation.
       - The upsampled caption.

4. ### `create_instr_conv_response_captions.py`

   - **Purpose**: Revise the original instructions based on the updated image captions and simulate multi-turn conversations.
   - **Functionality**:
     - Adjusts the original instructions from `autoredteam.py` to align with the new image captions.
     - Simulates multi-turn conversations between a user and an AI assistant.
       - Starts with pairs of:
         - (Original Instruction, Chosen Response)
         - (Revised Instruction, Chosen Response)
     - Produces conversations that reflect the changes in the captions and instructions.

## Getting Started

Follow the steps below to set up and run the pipeline.

### Installation

1. **Clone the repository:**

```bash
git clone https://github.com/yourusername/SafeLLM.git
cd safellm
```

2. **Install the required dependencies:**

```bash
pip install -r requirements.txt
```

### Usage
Run each script in the following order:

1. **Generate adversarial instructions:**
```bash
python autoredteam.py
```

2. **Create captions from instructions:**
```bash
python create_captions_from_instr.py
```

3. **Generate images and refine captions:**
```bash
python create_imgs_and_captions.py
```

4. **Revise instructions and simulate conversations:**
```bash
python create_instr_conv_response_captions.py
```

### Usage (Leonardo)

```bash
sbatch scripts/safe_pipe.sh
```
